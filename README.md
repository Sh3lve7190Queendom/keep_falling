# Keep Falling — E-commerce Site

E-commerce site for **Keep Falling**, a Colombian streetwear brand based in Medellín, built around a rave and techno aesthetic.

**Live preview:** https://keepfalling.netlify.app

## Tech stack

- Vanilla HTML, CSS, JavaScript (no frameworks, no build step)
- Hosted on Netlify, deployed via GitHub
- Typography: Bebas Neue, Space Grotesk (Google Fonts)

## Status

In active development. Target launch: July 2026.
